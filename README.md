# 마이링크 (MyLink)

나의 링크를 한곳에 모으는 반응형 웹페이지입니다.

## 전용 폴더

실제 웹페이지 소스는 [`mylink/index.html`](mylink/index.html)에 있습니다.
저장소 루트의 `index.html`은 `mylink/` 페이지로 연결합니다.

## 기능

- 링크 제목, 주소, 한 줄 소개 추가 및 수정
- 링크 삭제 전 확인, 링크 검색
- 빈 칸, 올바른 HTTP/HTTPS 주소, 중복 주소 검증
- 브라우저 로컬 저장 및 새로고침 후 유지
- 모바일 화면 지원 및 키보드 접근성
- 페이지 주소 복사

처음 방문하면 예시 링크 5개가 표시됩니다. 추가·수정한 목록은 각 방문자의 브라우저에만 저장됩니다. 다른 기기나 방문자에게 개인 링크 목록이 공유되지는 않습니다. 브라우저 사이트 데이터를 지우면 저장한 목록도 지워집니다.

## 실행

별도 라이브러리 설치나 빌드가 필요 없는 HTML/CSS/JavaScript 정적 사이트입니다.
로컬 HTTP 서버에서 저장소 폴더를 제공하거나 GitHub Pages로 배포할 수 있습니다.

## GitHub Pages 설정

저장소 Settings → Pages에서 Source를 `Deploy from a branch`, 배포 위치를 `main / (root)`로 설정했습니다.
공개 URL 접속과 HTTP 200 응답을 확인했습니다.
